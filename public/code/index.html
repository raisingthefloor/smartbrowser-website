Code

Everything this project produces is open source. Here is what exists, where it will live, and how to get it.

The proof-of-concept smart browser

The first-draft proof of concept described under Status is being prepared for public release. It will be published under the Apache License 2.0, which lets anyone use, change, and ship it, and includes an explicit patent grant from each contributor so that browser vendors can adopt the code with confidence.

  • Source code: a public repository on GitHub, separate from this website. Link to follow.
  • Installer: a downloadable build for people who want to try it without building it. The current version runs on Apple-silicon Macs with enough memory for a 14-billion-parameter model (about 12 GB in use). Link to follow.
  • What it is technically: to be described here when the repository opens: how it is built, which browser engine it sits on, and how the local model is loaded.

This website

The site is plain HTML, CSS, and a little JavaScript with no build step, so anyone can read and fix it. The repository is public: raisingthefloor/smartbrowser-website. Found a mistake or an accessibility problem? Open an issue. The dev branch is the shared draft; main is what you are reading.

Related open-source work

Open-source code by others that advances smart browsers will be listed here with the Library. Tell us about yours.

Contributing code

When the repository opens, contributions will follow the usual path: an issue first for anything larger than a fix, then a pull request. Contributors sign off their commits under the Developer Certificate of Origin; there is no contributor license agreement to sign. A code of conduct and contribution guide will be in the repository.

The settings vocabulary, the list of 85 things a person can ask for and what each means, is a contribution surface in its own right: proposals for new settings, better names, and clearer descriptions are welcome from anyone, especially from people with disabilities and the people who work with them. See the current list.

Smart Browser is an open collaboration to prove that a browser can fit any web page to the person using it. Everyone who joins the effort is part of it. This site is sponsored by Raising the Floor.
